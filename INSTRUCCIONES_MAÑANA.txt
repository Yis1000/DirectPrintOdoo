============================================================
       GUÍA IMPRESIÓN DIRECTA - WINDOWS Y LINUX
============================================================

El módulo Odoo ya funciona. Solo falta el worker que procesa la cola.

────────────────────────────────────────────────────────────
                    WINDOWS
────────────────────────────────────────────────────────────

PASO 1: Instalar dependencias
──────────────────────────────────────
Abrir PowerShell o CMD y pegar:

    pip install requests pypiwin32


PASO 2: Ver nombre de impresoras
──────────────────────────────────────
Win+R → escribir: control printers → Enter
Copia el nombre exacto de tus impresoras (ej: "HP LaserJet 1020")


PASO 3: Ejecutar worker (primera vez para probar)
──────────────────────────────────────
    cd C:\ruta\donde\esta\print_worker.py
    python print_worker.py


PASO 4: Instalar como servicio Windows (opcional, producción)
──────────────────────────────────────
Descargar NSSM: https://nssm.cc/download

Luego en CMD como administrador:

    nssm install OdooPrintWorker
    # En la ventana que abre:
    # Path: C:\Python311\python.exe  (o tu ruta de Python)
    # Startup directory: C:\ruta\de\odoo
    # Arguments: C:\ruta\de\odoo\print_worker.py

    nssm start OdooPrintWorker


────────────────────────────────────────────────────────────
                    LINUX / UBUNTU
────────────────────────────────────────────────────────────

PASO 1: Instalar dependencias
──────────────────────────────────────
    sudo apt update
    sudo apt install python3 python3-pip
    pip3 install requests


PASO 2: Verificar impresoras CUPS
──────────────────────────────────────
    lpstat -p

# Si necesitas agregar impresora a CUPS:
    sudo lpadmin -p 'NombreImpresora' -v 'socket://192.168.1.50:9100' -m 'everywhere'
    sudo cupsenable NombreImpresora


PASO 3: Copiar y dar permisos al worker
──────────────────────────────────────
    sudo cp print_worker.py /opt/odoo/
    chmod +x /opt/odoo/print_worker.py


PASO 4: Ejecutar worker (primera vez para probar)
──────────────────────────────────────
    cd /opt/odoo
    python3 print_worker.py


PASO 5: Instalar como servicio systemd (producción)
──────────────────────────────────────
    sudo cp print_worker.service /etc/systemd/system/
    sudo systemctl daemon-reload
    sudo systemctl enable print_worker
    sudo systemctl start print_worker

Ver estado:
    sudo systemctl status print_worker

Ver logs:
    sudo journalctl -u print_worker -f


────────────────────────────────────────────────────────────
            CONFIGURACIÓN EN ODOO (mismo para ambos)
────────────────────────────────────────────────────────────

PASO: Crear impresoras en Odoo
──────────────────────────────────────
Impresión Directa > Impresoras > Nueva

Ejemplo USB/Local:
┌─────────────────────────────────────────────┐
│ Nombre:           Almacén Facturas          │
│ Identificador:    HP LaserJet 1020          │ ← Nombre exacto del sistema
│ Tipo conexión:    USB / Local               │
│ Lenguaje:         PDF                       │
│ Activo:           ✓                         │
└─────────────────────────────────────────────┘

Ejemplo Red:
┌─────────────────────────────────────────────┐
│ Nombre:           Oficina Principal         │
│ Identificador:    192.168.1.50              │
│ Tipo conexión:    Red (TCP/IP)              │
│ Lenguaje:         PDF                       │
│ IP:               192.168.1.50              │
│ Puerto:           9100                      │
│ Activo:           ✓                         │
└─────────────────────────────────────────────┘


PASO: Crear configuraciones
──────────────────────────────────────
Impresión Directa > Configuraciones > Nueva

┌─────────────────────────────────────────────┐
│ Nombre:           Ventas - Almacén          │
│ Área:             Ventas                    │
│ Impresora:        (seleccionar)             │
│ Usuario:          (vacío = todos)           │
│ Auto imprimir:    □                         │
└─────────────────────────────────────────────┘


────────────────────────────────────────────────────────────
                    PROBAR
────────────────────────────────────────────────────────────

1. Inicia el worker (dejar corriendo)
2. En Odoo: Ventas > Ordenes > Abrir una orden
3. Clic en "Impresión Directa"
4. Debería imprimir en segundos
5. Verifica en: Impresión Directa > Cola de Impresión (estado: Success)


────────────────────────────────────────────────────────────
                COMANDOS ÚTILES
────────────────────────────────────────────────────────────
